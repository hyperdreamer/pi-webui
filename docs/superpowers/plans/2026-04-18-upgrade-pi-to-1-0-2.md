# Upgrade Pi Modules to 1.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use the deterministic subagent-driven-development controller to implement this plan task-by-task.

**Goal:** Upgrade `@earendil-works` Pi dependencies to 1.0.2, reconcile any API changes, pass all tests, and document the update with a changeset.

**Architecture:** Update `package.json` dependencies and `peerDependencies`, run `npm install`, adapt any changed types or signatures in the codebase, and verify build, lint, knip, and test suites.

**Tech Stack:** Node.js, TypeScript, npm, Vitest, `@earendil-works/pi-*`

## Global Constraints

Target version for @earendil-works/pi-agent-core, @earendil-works/pi-ai, and @earendil-works/pi-coding-agent is ^1.0.2.
peerDependencies floor must be updated to >=1.0.2 <2.
All tests, typecheck, lint, and knip must pass cleanly.
Do not introduce unrelated refactoring.
